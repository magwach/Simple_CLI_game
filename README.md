**🎮 CLI Rock, Paper, Scissors**

A simple interactive Rock, Paper, Scissors game built with Node.js and enhanced with colorful terminal output using `chalk`.

**🚀 Features**

    - Play against a computer opponent.
    - Colored terminal messages for better readability.
    - Repeats until the player chooses to exit.
    - Handles invalid input gracefully.

**🖥️ Demo**

    Choose rock, paper, or scissors: rock
    Computer chose: scissors
    You win!
    
    Play again? (y/n): n
    Thanks for playing!

**📦 Requirements**

    - Node.js (v14 or higher recommended)

**🛠️ Installation**

1. Clone the repository or download the code:

        git clone https://github.com/magwach/Simple_CLI_game.git
        cd cli-rock-paper-scissors
   
2. Install dependencies:

        npm install

**▶️ Usage**

To start the game, run:

    npm start
    
or directly with:

    node main.js
    
**🧱 Tech Stack**

    Node.js
    
    readline (for CLI input/output)
    
    chalk (for terminal colors)
